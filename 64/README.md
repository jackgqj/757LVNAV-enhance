# Local build

`win.xpl` in this folder is a local convenience build and is ignored by git
(`64/*.xpl` in `.gitignore`). GitHub release binaries are built by
`.github/workflows/build.yml` for Windows, macOS, and Linux.

To install the local build, place this `64` folder under:

```
X-Plane 12/Aircraft/Laminar Research/Boeing757-Full/plugins/757LVNAVPlus/
```
